# HousingPandaApp

HousingPandaApp is a full-stack web application that helps users search, save, and share rental listings with ease. Built with the MERN stack (MongoDB, Express, React, Node.js), it aims to simplify the apartment hunting experience.

## Features

- User authentication and profile management
- Search and filter rental listings
- Save favorites and share with friends
- Responsive design for mobile and desktop


## Installation

# Clone the repository
git clone https://github.com/BrianaPass/HousingPandaApp

cd HousingPandaApp

# Install dependencies
npm install

# Start the development server
npm start
